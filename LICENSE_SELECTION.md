# License Selection Note

This repository should not be published without an explicit license.

## Why this file exists

I cannot choose a legal license on your behalf. For a public academic code repository, you should add one concrete license file before publishing.

## Practical options

- `MIT`
  Good if you want very broad reuse with minimal conditions.
- `BSD-3-Clause`
  Similar to MIT, with a more explicit non-endorsement clause.
- `Apache-2.0`
  Good if you want an explicit patent grant.
- `CC-BY-4.0`
  Usually better for documentation or datasets than software code.

## Recommendation

If your institution and coauthors do not require something else, `MIT` or `BSD-3-Clause` is usually the simplest fit for a paper-companion code release.

After choosing, replace this file with a real `LICENSE` file.
